# DANEEL

> 🚧 In costruzione / Under construction

**IT** — DANEEL è un'app per Mac per fare live coding musicale dal vivo, pensata come un CDJ: una libreria di pezzi di codice pronti, una cuffia per provarli a tempo, e un'uscita live per le casse e il proiettore.

DANEEL è basato su [Strudel](https://strudel.cc) ([codice sorgente](https://codeberg.org/uzu/strudel)), il progetto di live coding di Felix Roos e della community di Strudel. Usa i pacchetti npm ufficiali di Strudel senza modificarli. DANEEL **non** è un progetto ufficiale di Strudel e non è affiliato ai suoi autori: tutto il merito del motore musicale è loro.

**EN** — DANEEL is a Mac app for live music coding, designed like a CDJ: a library of ready-made code snippets, a headphone cue to try them in time, and a live output for speakers and projector.

DANEEL is built on [Strudel](https://strudel.cc) ([source code](https://codeberg.org/uzu/strudel)), the live coding project by Felix Roos and the Strudel community. It uses the official Strudel npm packages, unmodified. DANEEL is **not** an official Strudel project and is not affiliated with its authors: all credit for the music engine goes to them.
